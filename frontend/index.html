Informations véhicule
À propos du modèle

Ce modèle utilise un MLPRegressor (scikit-learn) entraîné sur un jeu de données de ventes automobiles françaises (2020–2026).

Les features numériques subissent un pipeline de transformations : log · PowerTransform · StandardScaler

Les variables catégorielles (marque, modèle, énergie, carburant) sont encodées via OneHotEncoder.

L'intervalle de confiance à 95% est calculé à partir de l'écart-type résiduel du modèle sur le jeu de test.

Appeler l'API — Documentation

L'API expose un endpoint REST pour obtenir une estimation par requête JSON. Ci-dessous le format attendu, la réponse retournée, et des exemples prêts à l'emploi pour chaque langage.

Endpoint

POST /predict/full

Format de la requête (JSON)
ChampTypeDescriptionExemple
KilometragefloatKilométrage exact52335
Annee_FacturefloatAnnée de la facture2024

Exemples de code
Python
JavaScript
cURL

Librairie : requests — installer avec pip install requests 

import requests

url = "http://localhost:8001/predict/full"

payload = {
    "Kilometrage": 52335,
    "Annee_Facture": 2024,
    "Annee_veh": 2020,
    "Marque_veh": "CITROEN",
    "Modele_veh": "C5 AIRCROSS",
    "Type_Energie": "Thermique",
    "Carburant": "Diesel"
}

response = requests.post(url, json=payload)
data = response.json()

print(f"Prix estimé : {data['predicted_price']:.2f} €")
print(f"IC 95% : [{data['ic_0.95'][0]:.2f}, {data['ic_0.95'][1]:.2f}]")

API native : fetch — aucune dépendance nécessaire (navigateur ou Node 18+) 

const response = await fetch("http://localhost:8001/predict/full", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
        Kilometrage: 52335,
        Annee_Facture: 2024,
        Annee_veh: 2020,
        Marque_veh: "CITROEN",
        Modele_veh: "C5 AIRCROSS",
        Type_Energie: "Thermique",
        Carburant: "Diesel"
    })
});

const data = await response.json();
console.log("Prix estimé :", data.predicted_price);
console.log("IC 95% :", data["ic_0.95"]);

Format CSV attendu
Le fichier CSV doit contenir les 7 colonnes suivantes (séparateur : virgule) : 
Kilometrage,Annee_Facture,Annee_veh,Marque_veh,Modele_veh,Type_Energie,Carburant
52335,2024,2020,CITROEN,C5 AIRCROSS,Thermique,Diesel
9932,2020,2017,PEUGEOT,108 I Ph1,Thermique,Essence
120000,2023,2018,RENAULT,CLIO V,Thermique,Essence
Les colonnes supplémentaires sont conservées dans l'export mais ignorées par le modèle. L'export ajoute 3 colonnes : Prix_Predit, IC_95_Bas, IC_95_Haut, et une colonne Erreur en cas de problème.
