Informations véhicule
À propos du modèle

Ce modèle utilise un MLPRegressor (scikit-learn) entraîné sur un jeu de données de ventes automobiles françaises (2020–2026).

Les features numériques subissent un pipeline de transformations : log · PowerTransform · StandardScaler

Les variables catégorielles (marque, modèle, énergie, carburant) sont encodées via OneHotEncoder.

L'intervalle de confiance à 95% est calculé à partir de l'écart-type résiduel du modèle sur le jeu de test.
